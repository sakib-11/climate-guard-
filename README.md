### 🌱 Smart Climate Data Aggregation
> Collects live environmental data — temperature, rainfall, humidity, wind speed, solar radiation, and more — from multiple climate APIs in real time.

### 🌱 AI-Powered Insight Generation
> Uses **Google Gemini AI** to interpret trends, detect anomalies, and summarize environmental conditions in plain, human-readable language.

### 🌱 Live Climate Alert System
> Fetches verified disaster and weather alerts (floods, heatwaves, droughts, wildfires, etc.) for any region worldwide in real time.

### 🌱 Geo-Based Risk Scoring
> Calculates a **regional climate risk index** by combining real-time weather, air quality, and satellite data into a single score.

### 🌱 Dual-Model Disaster Prediction Simulator
> Built and trained using **EM-DAT** and **NASA Wildfire datasets**, predicting global disaster risks with over **98% ROC AUC accuracy** — powered by two complementary models:
> - **Random Forest** for explainable insights
> - **XGBoost** for high-performance forecasting

### 🌱 Interactive Map Visualization
> Displays dynamic, filterable risk maps with region-wise comparison and live updates — powered by Recharts.

### 🌱 Firebase Authentication
> Handles secure user sign-up, login, and session management with **Email/Password + Google OAuth**.

### 🌱 Firestore Cloud Database
> Stores user profiles, preferences, search history, and saved climate reports safely in the cloud.

### 🌱 Minimal, Responsive Dashboard
> Clean and fast UI built with **React + TailwindCSS + Shadcn UI**, designed for accessibility and clarity across all devices.

2. 🌱 User selects a **region or city** on the interactive map.
3. 🌱 Backend fetches **real-time environmental data** from global APIs.

### 🌿 Backend Setup

```bash
# 1. Clone the Repository
git clone https://github.com/your-username/ClimateGuard.git
cd ClimateGuard

# 2. Setup Backend
cd backend
python -m venv venv
source venv/bin/activate        # Linux/Mac
# venv\Scripts\activate         # Windows
pip install -r requirements.txt

# 3. Start the Backend
python start_backend.py
```

